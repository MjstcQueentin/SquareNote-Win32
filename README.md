# Square Note

This is a work in progress.

Square Note is an app in which users can create sticky notes, to-do lists and notebooks. This projects aims to provide users with an alternative to OneNote and To-Do, while keepings things as simple as possible.

## How to use

This project relies on the *Microsoft .NET* and *WinUI 3* Runtimes. Clone the repository, open it in Visual Studio 2022, install all NuGet packages, and build the project.
